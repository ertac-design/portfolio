# portfolio

Personal portfolio of Ertac Yavasca, Senior UI/UX and Product Designer.

Plain HTML, CSS and JavaScript, no build step. Published with GitHub Pages.

- `index.html`: home page with selected work
- `about.html`: about page
- `work/`: one page per project
- `assets/style.css`, `assets/main.js`: styles, page transitions and scroll reveals

Preview locally:
